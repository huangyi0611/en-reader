# 英语随读（en-overlay）安装说明 · iPhone Safari

滚动阅读英文网页时，每段英文下方会自动出现中文翻译，并附带「长句 / 俚语 / 短语」三个可折叠注释标签；点按任意英文单词会弹出详细中文释义。支持 X（x.com）、Reddit（新版 / old.reddit）以及各类英文书籍、文章网页。

## 一、安装 Userscripts App
1. 打开 App Store，搜索 **Userscripts**（开发者 **Justin Wasack / quoid**，免费），安装。
2. 打开一次 Userscripts App，点 **Change Userscripts Directory**（设置脚本目录），选一个文件夹，例如「iCloud 云盘 › Userscripts」。

## 二、在 Safari 中启用扩展
1. 打开 **设置 › App › Safari › 扩展**（旧版 iOS 为 设置 › Safari › 扩展）。
2. 点 **Userscripts**，打开开关。
3. 在「权限」里把 **所有网站** 设为 **允许**（或在 Safari 里第一次使用时点「始终允许 › 在所有网站上始终允许」）。
   - 不给"所有网站"权限的话，脚本只能在你逐个授权的网站上运行。

## 三、安装脚本（二选一）
**方法 A：打开脚本链接安装**
1. 在 Safari 中打开 `en-overlay.user.js` 的原始文件地址（raw 链接，地址以 `.user.js` 结尾）。
2. 点地址栏左侧的 **「大小」/ 拼图图标 › Userscripts**，弹出界面会显示「英语随读」，点 **Install（安装）**。

**方法 B：直接放进文件夹**
1. 把 `en-overlay.user.js` 文件存到 iPhone「文件」App 中第一步选择的 Userscripts 目录里（可以 AirDrop 到 iPhone 后「存储到文件」）。
2. 回到 Safari 刷新网页即可生效。

## 四、第一次使用
1. 打开任意支持的英文页面（例如 reddit.com 上的帖子），页面会弹出一个小面板。
2. 粘贴你的 **Kimi API Key**（形如 `sk-...`），点 **保存**。Key 只保存在本机脚本存储中。
3. 之后右下角会有一个小圆按钮「译」：
   - 点它打开设置面板：修改 Key、**暂停 / 继续**、开关「点按单词查释义」。
   - 红色数字 = 正在排队翻译的段落数；按钮变灰显示「Ⅱ」= 已暂停。

## 五、使用说明
- 段落滚动到屏幕附近时开始排队，离屏幕最近的先翻译；滚远了的段落会暂缓，滚回来再继续。
- Kimi 账号限速 **每分钟 3 次请求**，所以翻译会"慢慢冒出来"：首段一般 5–15 秒出现，之后大约每 20 秒一批（短推文/评论会多条合并成一次请求）。
- 翻译下方的「长句 n / 俚语 n / 短语 n」点一下展开，再点收起；灰色表示该段没有此类难点。
- 点按英文单词 → 弹出释义（含此处语境含义、词性、搭配、例句）。点空白处关闭。在 X 上点推文正文本来会进入详情页，开启查词后改为查词；要进详情页请点时间戳，或在面板里关掉查词。
- 结果按内容缓存在本机，同一段落再次出现不会重复请求。
- 通用模式（书籍/文章）只在页面语言为英文或正文大多为英文时自动运行；中文段落和很短的文字会被跳过。

## 常见问题
- **没反应**：确认 Safari 扩展里 Userscripts 已开启、对该网站「允许」；在 Userscripts App 中确认脚本是启用状态。
- **一直"排队翻译中"**：限速导致，耐心等待；或打开「译」面板看是否提示 API Key 无效 / HTTP 错误。
- **X 必须登录**：X 未登录时只显示登录页，脚本需要你在 Safari 中登录 X 后才能翻译时间线。
- **old.reddit 必须登录**：Reddit 现在要求登录才能使用 old.reddit，未登录请用 www.reddit.com。
